## 🚀 איך להעלות ל-GitHub ולהפעיל את GitHub Pages

### שלב 1: יצירת Repository חדש ב-GitHub
1. היכנס לחשבון שלך ב-[GitHub](https://github.com/new).
2. צור Repository חדש בשם לבחירתך (לדוגמה: `biochange-op-report`).
3. ודא שהמאגר מוגדר כ-**Public**.

### שלב 2: דחיפת הקוד (Push) מהמחשב
פתח טרמינל בתיקיית הפרויקט והרץ:

```bash
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git branch -M main
git push -u origin main
```

### שלב 3: הפעלת GitHub Pages
1. היכנס למאגר ב-GitHub ← עבור ל-**Settings**.
2. בתפריט הצד לחץ על **Pages** (תחת Code and automation).
3. תחת **Build and deployment** / **Source**:
   * בחר: **Deploy from a branch**
   * Branch: בחר ב-`main` ובתיקייה `/ (root)`.
4. לחץ **Save**.
5. תוך 1-2 דקות האתר יהיה זמין בכתובת:
   `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
